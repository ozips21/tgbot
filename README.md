### Telegram бот: погода в Москве в 09:00

Бот ежедневно отправляет погоду по Москве в 09:00 (Europe/Moscow) всем подписавшимся чатам.

### Быстрый старт

1) Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

2) Укажите токен бота. Получите у `@BotFather` и задайте переменную окружения `TELEGRAM_BOT_TOKEN`.

Можно создать файл `.env` (см. `.env.example`):

```bash
cp .env.example .env
# отредактируйте .env и вставьте реальный токен
```

3) Запустите бота:

```bash
python bot.py
```

### Команды

- `/start` — подписаться на ежедневную рассылку в 09:00
- `/stop` — отписаться
- `/now` — прислать погоду прямо сейчас

### Хранение подписчиков

Чаты сохраняются в файле `data/subscribers.json`. Если чат блокирует бота, он удаляется из списка при отправке.

### Примечания

- Время — 09:00 по `Europe/Moscow`.
- Погода берётся с `open-meteo.com` без ключа API.
